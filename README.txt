Dr. Naveena's Skin Clinic — website concept
=============================================

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet connection is needed only for the Google Fonts; the page itself works locally.

FILES
- index.html: page content
- style.css: pink/white responsive design
- script.js: mobile menu and demo appointment-form interaction
- assets/dr-naveena-photo.png: photo supplied for this concept

IMPORTANT BEFORE PUBLISHING
- This is a demonstration concept, not an official clinic website.
- The photo is used as supplied; no blazer transformation was applied to the source photo.
- Verify the clinic phone, address, current hours, qualifications, registration, actual services, and social links.
- Review cards are placeholders, not real testimonials. Replace with genuine reviews only when their wording, source, and permitted use are confirmed.
- Rating and review count are not hard-coded as a claimed live rating.
- The form is front-end only and does not send or store appointment requests.
- Ask the clinic for permission before using its name, photos, branding, or patient feedback publicly.
